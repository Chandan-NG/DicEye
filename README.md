# 🎲 DicEye

DicEye is a simple dice rolling web application built using **HTML**, **CSS**, **JavaScript**, and **Bootstrap**. It simulates rolling two dice by generating random values, updating the dice faces dynamically, and displaying a smooth rolling animation for an interactive experience. This project was built as a beginner-friendly exercise to practice DOM manipulation, event handling, responsive design, and basic JavaScript concepts.
